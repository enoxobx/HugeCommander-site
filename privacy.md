## Italiano

HugeCommander è un file manager che funziona interamente sul tuo computer.

**Nessun dato raccolto o inviato.** HugeCommander non raccoglie dati
personali, non usa statistiche d'uso, pubblicità o telemetria, e non invia
niente a noi né a terzi. Il programma non si collega a internet da solo: si
collega in rete solo alle cartelle condivise e ai computer che apri tu (per
esempio `\\server\condivisione`). Se quel computer chiede di accedere, nome
utente e password che scrivi vanno solo a lui, attraverso Windows; il
programma non li scrive in nessun file. Se scegli «Ricorda le credenziali»,
li conserva Windows nel suo Gestore credenziali, dove puoi toglierli.

**Cosa resta sul tuo computer.** Per funzionare, HugeCommander salva alcuni
file solo sul tuo computer:

- `%APPDATA%\HugeCommander\settings.json`: le tue preferenze, i preferiti,
  le schede salvate, le cartelle aperte all'ultima chiusura e le scorciatoie
  che hai cambiato.
- `%APPDATA%\HugeCommander\crash.log`: solo se il programma si chiude per un
  errore, il messaggio dell'errore e il punto del programma in cui è
  avvenuto. Resta sul tuo computer: lo invii tu, se vuoi, quando segnali un
  problema.
- `%APPDATA%\HugeCommander\grammars` e `%APPDATA%\HugeCommander\lang`:
  solo se ci metti tu dei file (grammatiche per i colori della sintassi,
  traduzioni).
- `%APPDATA%\HugeCommander\themes`: i temi che crei o importi (colori e
  caratteri).
- `%LOCALAPPDATA%\HugeCommander\index`: l'elenco dei nomi di file e cartelle
  dei dischi interni, per la ricerca istantanea. Si può disattivare nelle
  impostazioni (Ricerca).

**Cosa legge da altri programmi.** Se presenti, HugeCommander legge (senza
modificarli) le scorciatoie di Total Commander (`%APPDATA%\GHISLER\wincmd.ini`)
e le grammatiche dei colori di Visual Studio Code; i temi di Visual Studio
Code solo quando chiedi di importarne uno.

**Come cancellare i dati.** Disinstallando HugeCommander dal Microsoft Store,
o cancellando le cartelle `%APPDATA%\HugeCommander` e
`%LOCALAPPDATA%\HugeCommander`.

**Contatti.** Per domande su questa informativa: supporto@ESEMPIO-DA-DEFINIRE

## English

HugeCommander is a file manager that runs entirely on your computer.

**No data collected or sent.** HugeCommander does not collect personal data,
uses no usage statistics, advertising or telemetry, and sends nothing to us
or to third parties. The program never connects to the internet on its own:
it only connects to the shared folders and computers you open (for example
`\\server\share`). If that computer asks you to sign in, the user name and
password you type go only to it, through Windows; the program writes them
to no file. If you choose "Remember my credentials", Windows keeps them in
its Credential Manager, where you can remove them.

**What stays on your computer.** To work, HugeCommander saves a few files on
your computer only:

- `%APPDATA%\HugeCommander\settings.json`: your preferences, favorites,
  saved tabs, the folders open when you last closed it, and the shortcuts
  you changed.
- `%APPDATA%\HugeCommander\crash.log`: only if the program closes because of
  an error, the error message and where in the program it happened. It stays
  on your computer: you send it yourself, if you wish, when reporting a
  problem.
- `%APPDATA%\HugeCommander\grammars` and `%APPDATA%\HugeCommander\lang`:
  only if you put files there yourself (syntax color grammars,
  translations).
- `%APPDATA%\HugeCommander\themes`: the themes you create or import (colors
  and fonts).
- `%LOCALAPPDATA%\HugeCommander\index`: the list of file and folder names on
  the internal drives, for instant search. It can be turned off in the
  settings (Search).

**What it reads from other programs.** If present, HugeCommander reads
(without changing them) the Total Commander shortcuts
(`%APPDATA%\GHISLER\wincmd.ini`) and the Visual Studio Code color grammars;
Visual Studio Code themes only when you ask to import one.

**How to delete the data.** Uninstall HugeCommander from the Microsoft Store,
or delete the folders `%APPDATA%\HugeCommander` and
`%LOCALAPPDATA%\HugeCommander`.

**Contact.** For questions about this policy: supporto@ESEMPIO-DA-DEFINIRE
